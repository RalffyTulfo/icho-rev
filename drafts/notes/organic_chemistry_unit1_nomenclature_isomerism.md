# Organic Chemistry Unit 1: Nomenclature and Isomerism

## Goal
Teach IUPAC nomenclature for organic compounds (alkanes, alkenes, alkynes, aromatic compounds, functional groups), stereoisomerism (E/Z, R/S, meso compounds), and conformational isomerism (chair forms, Newman projections).

## Syllabus Coverage
- IUPAC nomenclature rules for all major functional groups
- Stereoisomerism: E/Z, R/S, optical activity, meso compounds
- Conformational isomerism: chair cyclohexane, Newman projections, ring flips
- Spectroscopic clues (IR, NMR) for isomer identification

## Difficulty
Three-tier problem sets:
- Warm-up: School-level problems
- Level-up: National olympiad-level problems
- Boss Fight: IChO-style problems

## Required Problems
- Name compounds from structures and draw structures from names
- Identify all stereoisomers for a given compound
- Determine R/S configuration and predict optical activity
- Analyze chair conformations and predict the most stable form
- Use spectroscopic data to distinguish isomers

## Spectroscopic Clues
- **IR Spectroscopy**: Identify functional groups via peak positions (e.g., 3000 cm⁻¹ for C-H, 1700 cm⁻¹ for C=O).
- **NMR Spectroscopy**: Determine molecular structure using proton shifts (e.g., 1.0–2.0 ppm for methyl groups).
