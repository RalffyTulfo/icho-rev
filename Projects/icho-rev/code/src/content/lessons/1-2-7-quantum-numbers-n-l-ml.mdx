# Quantum numbers (n, l, ml)
## 1. Prerequisites

1.2.5 for where the integers come from and 1.2.6 for what a probability distribution means. This
card is the inventory: which combinations of integers describe an orbital, and how many electrons
each combination admits.

## 2. Hook

Four integers describe an electron completely, and three of them are not independent: pick n and l
and most of the allowed values of m_l are already decided. That nesting is the periodic table in
miniature, and it is why the table has blocks of width 2, 6, 10 and 14 instead of a uniform grid.
Where this analogy breaks: quantum numbers label states, not addresses; two electrons can share an
address in space only by differing in spin.

## 3. Core idea

An orbital is fixed by (n, l, m_l): n sets the shell and energy in hydrogen, l sets the shape and the
angular node count, m_l sets the orientation. Spin adds m_s = ±½. The allowed values are nested —
l runs from 0 to n − 1, m_l from −l to +l — so a subshell has 2l + 1 orbitals and a shell has n²
orbitals, 2n² electrons. The Pauli principle then allows at most two electrons per orbital.

## 4. Definition

**Principal quantum number** n = 1, 2, 3, …: shell, size, energy (hydrogen). **Azimuthal (orbital)
quantum number** l = 0, 1, …, n − 1: shape; labels s, p, d, f for l = 0, 1, 2, 3. **Magnetic quantum
number** m_l = −l, …, 0, …, +l: orientation, 2l + 1 values. **Spin quantum number** m_s = +½ or −½.
An **orbital** is one allowed (n, l, m_l) set; a **subshell** is all orbitals with the same n and l.

## 5. How it works

**Step 1: the nesting.** n fixes the maximum l; l fixes the maximum |m_l|. So for n = 3, l may be 0,
1 or 2; for l = 2, m_l may be −2, −1, 0, +1, +2. A set such as n = 2, l = 2 is impossible, and a set
such as n = 3, l = 1, m_l = 2 is impossible. Any exam question that hands you such a set expects you
to reject it immediately.

**Step 2: counting orbitals.** For each l there are 2l + 1 values of m_l. Summing over l = 0 to n − 1:

Σ(2l + 1) = n². Proof by induction: for n = 1 the sum is 1 = 1²; adding the next term 2(n − 1) + 1 =
2n − 1 to n² gives n² + 2n − 1, which is not (n + 1)². The correct statement is that the sum of the
first n odd numbers 1 + 3 + … + (2n − 1) = n², and the terms here are exactly those odd numbers, so
the identity applies term by term.

With spin, the shell holds 2n². For n = 1, 2, 3, 4 that is 2, 8, 18, 32 — the shell capacities, not the table's row lengths.
The visible row lengths are 2, 8, 8, 18, 18, 32, because 4s fills before 3d and 5s before 4d; capacity and row length are different lists.

**Step 3: labels.** Combine n with the letter for l: 1s, 2s, 2p, 3s, 3p, 3d, 4s, 4p, 4d, 4f. The
number of orbitals is written as a superscript when filling: 2p⁶ means three 2p orbitals holding six
electrons, not six orbitals.

**Step 4: Pauli and Hund.** Pauli: no two electrons in an atom may share all four quantum numbers,
which is why an orbital holds two (same n, l, m_l; opposite m_s). Hund: within a subshell the
lowest-energy arrangement maximises total spin, so electrons singly occupy degenerate orbitals with
parallel spins before pairing. Pauli is a rule about allowed states; Hund is about which allowed
state is lowest in energy.

**Step 5: what is exact and what is bookkeeping.** The allowed ranges are exact consequences of the
hydrogen solution. The energy depending only on n is exact only for hydrogen; in multi-electron atoms
l matters, which is why 2s and 2p differ and why the aufbau order is not simply 1s 2s 2p 3s 3p 4s 3d.
The labels s, p, d, f are historical names for l values, not descriptions of shape.

**Step 6: reading a configuration.** In 1s²2s²2p⁶, the superscripts count electrons in that subshell;
the sum of superscripts equals the electron count. For a neutral atom that equals Z, which is the
fastest check that a configuration is not nonsense.

## 6. Diagram

Draw a table: rows for n = 1 to 4; columns for l = 0 to 3 with the letter labels; each cell lists
2l + 1 and the number of electrons 2(2l + 1). Shade the cells that do not exist (l ≥ n) to make the
triangle shape visible, and write the running totals 2, 8, 18, 32 at the row ends.

## 7. Assumptions and limits

The quantum numbers above describe a single electron in a central field. In a real atom, electron
repulsion mixes configurations, so a configuration like 3d⁵4s¹ is a label for a state rather than a
complete description; term symbols and configuration interaction are needed beyond this card. Spin is
added empirically and is not contained in the non-relativistic Schrödinger equation. Magnetic
quantum numbers also describe the response to an external field, not a property you can observe in
zero field.

## 8. Worked example

**Given.** The shell n = 3.

**Hanapin.** The allowed l and m_l values, the number of orbitals, the number of electrons, and
whether (n = 3, l = 1, m_l = 2) is allowed.

**Solusyon.** Step 0: write the ranges before listing anything.

l = 0, 1, 2 (three subshells).
l = 0: m_l = 0 → 1 orbital.
l = 1: m_l = −1, 0, +1 → 3 orbitals.
l = 2: m_l = −2, −1, 0, +1, +2 → 5 orbitals.

Total orbitals: 1 + 3 + 5 = 9 = n². Electrons: 2 × 9 = 18 = 2n².

The set (3, 1, 2) is not allowed because |m_l| must be at most l, and 2 is greater than 1. The
correct maximum for l = 1 is m_l = +1.

**Sagot.** Nine orbitals (3s, three 3p, five 3d), eighteen electrons, and (3, 1, 2) is invalid.

## 9. Traps

1. Allowing l = n. The maximum is n − 1; 1s exists, 1p does not.
2. Allowing |m_l| greater than l, as in (2, 1, 2). The m_l range is set by l, not by n.
3. Confusing subshell and orbital counts: 2p is 3 orbitals, 2p⁶ is 6 electrons, and the subshell
   capacity is 6, not the orbital's 2.
4. Counting 2n² orbitals. 2n² counts electrons; orbitals are n².
5. Using Hund's rule as if it were Pauli. One forbids states, the other orders energies.
6. Assigning spin to an orbital rather than an electron. m_s belongs to the electron, not to the
   (n, l, m_l) set.
7. Believing all orbitals with the same n are degenerate in every atom. Only in hydrogen (and
   hydrogen-like ions).

## 10. Check questions

1. How many orbitals are there in the 4p subshell, and how many electrons can it hold?
   2l + 1 = 3 orbitals; 6 electrons.
2. Is (n = 4, l = 4) allowed? Is (n = 4, l = 3, m_l = −3)?
   (4, 4) is not allowed because l must be at most n − 1 = 3. (4, 3, −3) is allowed: l = 3 gives m_l
   from −3 to +3.
3. How many electrons in an atom can have n = 2?
   Eight, from 2n² = 8: 2s² 2p⁶.
4. Why does the 3d subshell fill after 4s in the aufbau sequence if 3d has a lower n?
   The filling sequence is a heuristic about the order configurations are built in, not an orbital-energy
diagram. For neutral atoms with Z at least 21 the 3d orbital lies below 4s; the sequence still places 4s
first because it tracks the total energy of the atom as electrons are added. Do not read it as a
statement that 4s is lower in energy.
