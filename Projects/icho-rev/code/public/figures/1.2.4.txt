Five panels. d_xy, d_xz and d_yz each show four lobes between the axes with two dashed nodal planes labelled x = 0, y = 0, x = 0, z = 0 and y = 0, z = 0; d_x2-y2 shows four lobes along x and y with the two diagonal planes x = y and x = -y. Each of those four has 2 nodal planes and 0, 1 or 2 radial nodes according to n = 3, 4, 5. The fifth panel, d_z2, shows two lobes along z and a torus in the xy plane of opposite sign, cut by two red dashed cones at 54.7 and 125.3 degrees from +z, where 3cos^2(theta) - 1 = 0. The angular function is not 2cos^2(theta) - 1, which has no zero at those angles.
