# Skill Selection for IChO Website

## Selected Skills for IChO Project

### Frontend & Design (4 core skills)
1. **ui-ux-pro-max** - Builds professional company websites at Figma/x.ai level with:
   - Plain copy in its own voice
   - One section per screen
   - Equal edges
   - Real photographs and product UI
   - Hero entrance and two dealt moments per page
   - Shader effects and scenes on tech pages
   - Quiet micro-interactions
   - Checker and finish gate enforced in real browser

2. **design-taste-frontend** - tasteskill 2.5.1, anti-slop frontend skill with:
   - Professional website standards
   - Plain copy in a voice of its own
   - One system, one section per screen
   - Equal edges
   - Real photographs and real product UI
   - Hero entrance and one or two dealt moments on every page
   - Shader effects and scenes only on tech, gaming and software pages
   - Quiet micro-interactions
   - Checker and finish gate that enforces it in a real browser

3. **emil-design-eng** - Emil Kowalski's philosophy on UI polish, component design, animation decisions, and invisible details

4. **extract-design-system** - Extract design primitives from website and generate starter token files

### Motion & Animation (3 skills)
5. **animation-performance** - Keep web animations inside frame budget, animate composite-only properties, move off main thread when busy, find cause when animation drops frames

6. **animation-vocabulary** - Reverse-lookup glossary for animation terms

7. **choreograph** - Coordinate several elements that animate together

### Quality Review (1 skill)
8. **review-animations** - User-only motion review skill (I must run manually at checkpoints)
