# IChO Official Syllabus Map & Architecture Decision

## 1. Executive Summary & Official Syllabus Framework

The International Chemistry Olympiad (IChO) official syllabus categorizes topics into three distinct difficulty levels according to the IChO Steering Committee guidelines:

- **Level 1 (Core High School / Introductory Olympiad):** Topics included in standard high school chemistry curricula worldwide. Expected to be known by all participants without explicit mention.
- **Level 2 (Standard IChO Syllabus):** Topics included in the official IChO syllabus that must be mastered for the competition, but are covered in standard introductory university general and organic chemistry.
- **Level 3 (Advanced / Host-Specific Preparatory Topics):** Topics that go beyond the standard syllabus. Host countries publish these in their annual **Preparatory Problems** (typically released in January before the July competition). These require specialized advanced study.

### Official Guidelines & External Resource Links
> **Note on Copyright & Problem Integrity:** In compliance with IChO regulations and copyright guidelines, this platform **never copies or reproduces copyrighted IChO competition exam problems directly**. All links point to official repositories, and practice materials utilize original, freshly authored problem sets modeled after Olympiad concepts.

## 2. Domain Difficulty Mapping

Below is the breakdown of topics across all core chemistry domains mapped to IChO difficulty levels (Level 1, Level 2, Level 3).

### A. Physical Chemistry
| Topic | Level | Description / Notes |
| :--- | :---: | :--- |
| Ideal Gas Law & Kinetic Molecular Theory | Level 1 | State equations, Dalton's law, Graham's law. |
| First Law of Thermodynamics & Calorimetry | Level 1/2 | Enthalpy, Hess's Law, heat capacity ($C_p, C_v$). |
| Second & Third Laws, Entropy & Gibbs Energy | Level 2 | $\Delta G^\circ = -RT \ln K$, temperature dependence of equilibrium constants (van 't Hoff equation). |
| Chemical Equilibrium & Le Chatelier | Level 1 | Homogeneous and heterogeneous gas/solution equilibria. |
| Electrochemistry & Nernst Equation | Level 2 | Standard potentials, cell thermodynamics ($\Delta G = -nFE^\circ$), concentration cells, electrolysis. |
| Reaction Kinetics & Rate Laws | Level 2 | Integrated rate laws (0th, 1st, 2nd order), Arrhenius equation, activation energy. |
| Steady-State Approximation & Enzyme Kinetics | Level 3 | Complex kinetic mechanisms, Michaelis-Menten kinetics, pre-equilibrium approximations. |
| Quantum Chemistry & Atomic Spectroscopy | Level 2/3 | Bohr model, quantum numbers, orbital shapes, particle-in-a-box model, Beer-Lambert law. |
| Phase Equilibria & Binary Phase Diagrams | Level 3 | Clausius-Clapeyron equation, Raoult's and Henry's laws, eutectic points, lever rule. |

### B. Organic Chemistry
| Topic | Level | Description / Notes |
| :--- | :---: | :--- |
| IUPAC Nomenclature & Structure Drawing | Level 1 | Basic alkanes, alkenes, alkynes, functional group priorities. |
| Stereochemistry & Conformational Analysis | Level 2 | $R/S$ configuration, $E/Z$ isomerism, Fischer projections, Newman projections, chair conformations. |
| Nucleophilic Substitution & Elimination ($S_N1, S_N2, E1, E2$) | Level 2 | Stereochemical outcomes, substrate/solvent/leaving group effects, Zaitsev/Hoffmann rules. |
| Electrophilic Addition & Aromatic Substitution | Level 2 | Markovnikov addition, carbocation rearrangements, substituent directing effects ($o/p$ vs $m$). |
| Carbonyl Chemistry & Enolates | Level 2/3 | Aldol, Claisen, Dieckmann condensations, Michael addition, Wittig reaction, Robinson annulation. |
| Pericyclic Reactions & Frontier Molecular Orbitals | Level 3 | Diels-Alder reaction stereochemistry, FMO analysis, electrocyclic ring opening/closing rules. |
| Retrosynthetic Analysis & Protecting Groups | Level 3 | Disconnection approach, synthons, functional group interconversions (FGI), acetal/silyl protector strategies. |
| Heterocyclic & Biomolecular Organic Synthesis | Level 3 | Pyridine, pyrrole, furan reactivity, peptide synthesis (protecting groups like Boc, Fmoc). |

### C. Inorganic Chemistry
| Topic | Level | Description / Notes |
| :--- | :---: | :--- |
| Periodic Trends & Main Group Chemistry | Level 1/2 | Ionization energy, electronegativity, atomic radii, reactivity of s- and p-block elements. |
| Chemical Bonding & Molecular Geometry | Level 1/2 | VSEPR theory, hybridization, Lewis structures, formal charges, resonance. |
| Molecular Orbital (MO) Theory | Level 2/3 | Diatomic MO diagrams ($\text{B}_2, \text{C}_2, \text{N}_2, \text{O}_2, \text{F}_2, \text{CO}, \text{NO}$), bond order, magnetism. |

| Solid State Chemistry & Crystallography | Level 2/3 | Unit cells (simple cubic, bcc, fcc, hcp), Bragg's law ($n\lambda = 2d\sin\theta$), crystal lattice energy (Born-Haber cycle). |
| Organometallic Chemistry | Level 3 | 18-electron rule, ligand types ($\sigma$-donors, $\pi$-acceptors), catalytic cycles (catalytic hydrogenation, cross-coupling). |

### D. Analytical Chemistry
| Topic | Level | Description / Notes |

## 3. Technology Stack Architecture Decision: Astro + MDX

To deliver this curriculum cleanly, efficiently, and with zero ongoing server maintenance costs, we explicitly adopt **Astro + MDX** as the core web stack for the `icho-rev` platform.

### Why Astro + MDX (Over Raw HTML or Traditional SPA Frameworks)?

1. **Content-First for Educators & Authors:**
   - Chemistry content lives in standard Markdown (`.mdx`) files stored directly in Git.
   - Teachers, researchers, and content authors can edit lesson files without writing complex HTML or JavaScript boilerplate.
   - Frontmatter handles metadata (unit name, prerequisites, difficulty level, estimated completion time).

2. **Zero-JavaScript Static Build with Island Architecture:**
   - Astro compiles pages down to pure, static HTML/CSS by default, making page loads blazing fast on mobile devices or lower-bandwidth networks.
   - Interactive components (e.g., titration simulators, 3D molecule viewers, practice quiz widgets) run as **Astro Islands** (using React/Vue/Svelte components), hydrating JavaScript *only* where interactivity is required.

3. **Full Interactive MDX Component Integration:**
   - MDX allows custom UI widgets directly inside markdown text:
     ```mdx
     # Electrophilic Addition to Alkenes

     Recall the carbocation stability hierarchy:

     <InteractiveMolecule pdbId="1abc" label="Tertiary Carbocation" />

     <SelfCheckQuiz problemId="org-eq-04" />
     ```

4. **Zero Backend & GitHub Pages Compatibility:**
   - Static builds generate a pure static site ready for deployment on GitHub Pages or Vercel.
   - **Subpath Support:** Astro natively configures `site` and `base` (`base: '/icho-rev/'`) in `astro.config.mjs`, ensuring all asset paths, internal links, and routes render seamlessly under GitHub Pages subpaths.

5. **LaTeX & Chemical Equation Rendering:**
   - Integrated `remark-math` and `rehype-katex` plugins render mathematical and chemical formulas ($\Delta G^\circ = -RT\ln K$, $\text{pH} = \text{p}K_a + \log\frac{[\text{A}^-]}{[\text{HA}]}$) cleanly at build time with crisp typography.
